# FIS World Cup data

Updated automatically twice a day by GitHub Actions (see the Actions tab).

- `data/fis_history.csv`: seasons 2021/22 to 2025/26, uploaded once.
- `data/fis_<season>_runs.csv`: all results of the current season so far.
- `data/startlists/`: start lists for races in the next three days, as soon as FIS publishes them.
- `data/status.json`: when the last update ran and what it found.

Run it by hand: Actions tab -> FIS daily update -> Run workflow.
